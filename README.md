# Life in the UK Exams

A WordPress-based exam preparation platform for the Life in the UK Test, featuring a custom-built practice test system and study resources for users preparing for UK citizenship.

---

## 📘 Overview

Life in the UK Exams is an educational website designed to help users prepare for the official **Life in the UK Test**, a requirement for British citizenship.

The platform provides:
- Practice exams
- Study materials
- Guidance content

A key part of the project was building a **custom exam system plugin** to simulate real test conditions and improve user learning experience.

---

## 🚀 Key Features

- **Practice Test System**
  - Timed or structured exam-style quizzes
  - Multiple-choice questions
  - Immediate feedback and scoring

- **Study Resources**
  - Guides and preparation materials
  - Structured content for learners

- **User-Friendly Interface**
  - Simple navigation for quick access to tests
  - Mobile-friendly design

- **Content Platform**
  - Built on WordPress for easy content management and scalability

---

## 🛠 Tech Stack

- **Frontend / CMS:** WordPress  
- **Backend Logic:** Custom PHP plugin  
- **Database:** MySQL (via WordPress)  
- **Hosting / Deployment:** Standard web hosting environment

## 🔧 Custom Plugin Functionality

A custom-built plugin was developed to provide exam functionality not available in default WordPress features.

### Core Capabilities:
- Dynamic question rendering  
- Answer selection and validation  
- Score calculation and result display  
- Basic quiz flow control  

### Purpose:
- Simulate real exam conditions  
- Provide interactive learning instead of static content  
- Improve user engagement and retention
